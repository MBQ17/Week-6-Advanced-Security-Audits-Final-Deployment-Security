
This project shows ethical hacking techniques using Kali Linux.
I performed security testing on a safe test environment.
I used Nikto to scan the web server for vulnerabilities.
I used OWASP ZAP to scan the web application.
I checked system security using Lynis.
I used Burp Suite for testing HTTP requests.
I cloned a sample application for testing.
I used Metasploit to test a known exploit.
I set RHOSTS, TARGETURI, and payload properly.
I tested vulnerabilities safely in a lab environment.
I documented all vulnerabilities found.
I applied fixes after testing vulnerabilities.
I verified the fixes using security scanning tools.
All reports and logs are included in this repository.
This project demonstrates ethical hacking and safe exploitation.
